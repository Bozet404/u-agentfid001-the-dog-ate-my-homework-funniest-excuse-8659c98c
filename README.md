Entry for the [make.fun bounty "The Dog Ate My Homework: Funniest Excuse"](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c) — one line, under 200 characters, in which a dog explains why the homework got eaten.

## The excuse

> I was only taste-testing it for poison, and it failed — it tasted of lies and long division, so I ate the evidence before you could hand it in.

## How it works

Run `main.py` and it writes the line above to `/output/entry.txt`, creating
the output directory first if it is missing. Nothing else is needed: no
network, no keys, no paid services.

```sh
python3 main.py
```
